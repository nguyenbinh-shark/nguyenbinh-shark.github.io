    Thành quả của series: thư viện shark_pidWhat the series produced: the shark_pid library

    shark_pid — mã nguồn mở, giấy phép MIT

    Toàn bộ kỹ thuật của 5 bài thực chiến, gói lại thành một thư viện dùng được thật. Lõi C99 không phụ thuộc Arduino hay HAL nên cùng một file chạy trên STM32, ESP-IDF, Arduino và cả trên PC để mô phỏng — kèm vỏ bọc C++ cho ai quen cú pháp class.

      
    Kích thước1700 byte Flash · 0 byte RAM tĩnh (Cortex-M4)
    Điểm cốt lõidt là tham số tường minh — đổi vòng lặp 1 kHz xuống 50 Hz chỉ lệch đỉnh 0.03 °C, so với 2.51 °C của thiết kế không có dt
    Ngoài giáo trìnhSetpoint weighting 2 bậc tự do, feedforward, chống windup back-calculation, chống NaN
    Kiểm chứng41 assertion chạy tự động trên CI với gcc + clang, ASan/UBSan, cross-compile Cortex-M0/M4, Arduino Lint
    # platformio.ini
lib_deps = https://github.com/nguyenbinh-shark/shark_pid.git

    Kèm bảng đối chiếu chi tiết với SimpleFOC và PID_Library — giải thích từng quyết định thiết kế, những chỗ hở trong hai thư viện gốc, và công thức quy đổi hệ số khi chuyển sang.

    shark_pid — open source, MIT licence

    Every technique from the five hands-on articles, packaged as a library you can actually ship. The core is C99 with no dependency on Arduino or any HAL, so the same file runs on STM32, ESP-IDF, Arduino and on a PC for simulation — with a C++ wrapper for anyone who prefers classes.

      
    Size1700 bytes of Flash · 0 bytes of static RAM (Cortex-M4)
    Core ideadt is an explicit argument — dropping the loop from 1 kHz to 50 Hz shifts the peak by only 0.03 °C, against 2.51 °C for a design without dt
    Beyond the textbookTwo-degree-of-freedom setpoint weighting, feedforward, back-calculation anti-windup, NaN guards
    Verification41 assertions run automatically in CI under gcc and clang, ASan/UBSan, Cortex-M0/M4 cross-compilation and Arduino Lint
    # platformio.ini
lib_deps = https://github.com/nguyenbinh-shark/shark_pid.git

    It comes with a detailed comparison against SimpleFOC and PID_Library — each design decision explained, the gaps in both original libraries, and the formulas for converting gains when you switch.

    Gợi ý lộ trình học tập: Nếu bạn mới làm quen với điều khiển tự động, hãy bắt đầu từ PID Dành Cho Người Không Chuyên để xây dựng cảm giác trực quan. Nếu bạn đã nắm nguyên lý và muốn triển khai ngay trên Arduino/ESP32, hãy chuyển sang Lập trình thực chiến.

    Suggested route: if automatic control is new to you, start with PID for Non-Specialists to build the intuition. If you already know the principles and want to get it running on an Arduino or ESP32, go straight to Hands-On Programming.
