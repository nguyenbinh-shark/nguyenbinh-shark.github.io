    Bản đồ 3D SLAM thời gian thực với LiDAR Livox Mid-360 trên Raspberry Pi 5 Real-Time 3D LiDAR SLAM Mapping with Livox Mid-360 on Raspberry Pi 5

    Hệ thống SLAM 3D LiDAR-Inertial độc lập chạy trực tiếp trên Raspberry Pi 5 (Ubuntu 24.04 ARM64, ROS 2 Jazzy), chỉ sử dụng cảm biến Livox Mid-360 qua kết nối Ethernet cùng IMU 200 Hz tích hợp để dựng bản đồ điểm 3D và quỹ đạo thời gian thực mà không cần encoder bánh xe, camera hay mạch STM32.

    A standalone 3D LiDAR-Inertial SLAM system running directly on a Raspberry Pi 5 (Ubuntu 24.04 ARM64, ROS 2 Jazzy), using only a Livox Mid-360 over Ethernet and its built-in 200 Hz IMU to build real-time 3D point-cloud maps and trajectories without wheel encoders, cameras, or an STM32 controller.

    Điểm nổi bật

    • Pipeline LiDAR-Inertial độc lập: Đóng gói gọn trên ROS domain 21 (MID-360 → Livox SDK2 → livox_ros_driver2 → FAST-LIO2 → RTAB-Map), không phụ thuộc encoder hay STM32.
    • Odometry & tối ưu đóng vòng 3D: FAST-LIO2 cung cấp odometry 10 Hz (voxel 0,2 m, TF camera_init → body), kết hợp RTAB-Map dùng ICP Point-to-Plane và GTSAM tối ưu đồ thị đóng vòng (keyframe tối đa 1 Hz, TF map → camera_init), hỗ trợ định vị lại (localize) trên DB đã lưu.
    • Quản lý phiên & dữ liệu an toàn: Mỗi lần chạy tạo thư mục riêng sessions/YYYYMMDD-HHMMSS_id/ lưu map.db, map_cloud.ply (voxel 0,1 m), map_poses.txt, odometry.csv và rosbag MCAP (tự tách mỗi 60 s hoặc 2 GB); hỗ trợ snapshot trực tuyến không dừng SLAM và phát lại replay từ raw.
    • Bộ công cụ giám sát trên Windows: Viewer 3D qua SSH (không cần cấu hình DDS trên Windows), Open3D GPU dense viewer (voxel 3 cm) kèm phát lại góc nhìn POV, và ứng dụng MID360 Radio Map (PyInstaller EXE) hỗ trợ điều khiển SLAM offline cùng xem bản đồ 2D theo tầng / 3D thưa qua LoRa E22-433T22D.
    • Ổn định trên ARM64: Đồng bộ thư viện spdlog hệ thống tránh lỗi ABI khi thoát, giữ cảm biến tối thiểu 3 s để khởi tạo IMU, 5/5 chu kỳ tắt driver sạch bằng SIGINT và khóa phần cứng chống khởi chạy trùng lặp.

    Key highlights

    • Standalone LiDAR-Inertial pipeline: Self-contained on ROS domain 21 (MID-360 → Livox SDK2 → livox_ros_driver2 → FAST-LIO2 → RTAB-Map), requiring no wheel encoders or STM32.
    • 3D odometry & loop-closure optimization: FAST-LIO2 produces 10 Hz odometry (0.2 m voxel, TF camera_init → body), paired with RTAB-Map Point-to-Plane ICP and GTSAM pose-graph loop closure (up to 1 Hz keyframes, TF map → camera_init), including localize mode on saved maps.
    • Session & data isolation: Every run writes to sessions/YYYYMMDD-HHMMSS_id/ with map.db, map_cloud.ply (0.1 m voxel), map_poses.txt, odometry.csv, and MCAP rosbags (split every 60 s or 2 GB), supporting non-disruptive live snapshots and full raw replay.
    • Windows desktop tooling: SSH 3D preview viewer (zero DDS setup on Windows), GPU-accelerated Open3D dense viewer (3 cm voxel) with 3D POV trajectory replay, and the MID360 Radio Map PyInstaller EXE for offline SLAM control plus per-floor 2D and sparse 3D viewing over LoRa E22-433T22D.
    • ARM64 reliability: Linked against system spdlog to eliminate exit ABI crashes, enforces ≥ 3 s static IMU initialization, verified 5/5 clean SIGINT driver shutdowns, and uses hardware lock guards against duplicate processes.
