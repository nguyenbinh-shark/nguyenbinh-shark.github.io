    Bộ Điều Khiển Robot Vi Sai ROS 2 Gốc trên STM32H723 (micro-ROS) Native ROS 2 Differential-Drive Robot Controller on STM32H723 (micro-ROS)

    Hệ thống bộ điều khiển robot vi sai thời gian thực (differential mobile robot controller) xây dựng trên vi điều khiển STM32H723VGT6 (ARM Cortex-M7 @ 192 MHz) giao tiếp trực tiếp với ROS 2 Jazzy thông qua middleware micro-ROS qua cổng USB CDC ACM. Firmware loại bỏ hoàn toàn các nút cầu nối chuỗi tự chế (custom serial bridge), tích hợp hai bus FDCAN độc lập điều khiển động cơ servo RobStride, thuật toán định hướng AHRS Mahony 1 kHz, bộ ước lượng vận tốc Kalman thích nghi (Adaptive Kalman Filter) chống trượt bánh và màn hình chẩn đoán trạng thái ST7789 IPS LCD.

    A real-time differential-drive robot controller built on the STM32H723VGT6 (ARM Cortex-M7 @ 192 MHz), talking to ROS 2 Jazzy directly through the micro-ROS middleware over USB CDC ACM. The firmware removes the home-made serial bridge entirely and brings together two independent FDCAN buses driving RobStride servo motors, a 1 kHz Mahony AHRS, an adaptive Kalman velocity estimator that rejects wheel slip, and an ST7789 IPS LCD status display.

    Mục tiêu

    Thiết kế, xây dựng và tối ưu hóa một hệ thống điều khiển robot nhúng chuẩn công nghiệp, đưa vi điều khiển trở thành node ROS 2 gốc (first-class citizen) với độ trễ thấp, tính thời gian thực cao, đảm bảo an toàn phần cứng thông qua các cơ chế chẩn đoán đa tầng và quản lý tài nguyên bộ nhớ nghiêm ngặt.

    Tính năng kỹ thuật nổi bật

    • Node ROS 2 Gốc (Native micro-ROS on USB CDC): Giao tiếp trực tiếp với đồ thị tính toán ROS 2 qua Micro-XRCE-DDS Client ở tốc độ 12 Mbit/s, hỗ trợ đầy đủ hợp đồng kiểu dữ liệu tĩnh (sensor_msgs/JointState, geometry_msgs/Twist) và các chính sách QoS (Reliable cho lệnh, Best Effort cho telemetry).
    • Quản lý phiên DDS tự phục hồi (4-Phase State Machine with Ping Hysteresis): Máy trạng thái 4 pha quản lý vòng đời node, tích hợp cơ chế trễ ping (3s / 150ms timeout / 3 misses) triệt tiêu hoàn toàn hiện tượng nhấp nháy mất node (topic flickering) khi bus USB bị jitter.
    • Ráp message tĩnh hoàn toàn (Zero-Dynamic Allocation): Toàn bộ mảng chuỗi và vector của JointState được gắn sẵn trên bộ nhớ tĩnh, triệt tiêu 100% rủi ro phân mảnh bộ nhớ (heap fragmentation) trong chu trình điều khiển thời gian thực.
    • Kiến trúc Dual-FDCAN cho Động cơ RobStride: Điều khiển 2 động cơ độc lập trên FDCAN1 và FDCAN3 ở tốc độ 1 Mbit/s cùng Node ID 1 xuất xưởng, cho phép thay thế nóng linh kiện mà không cần nạp lại ID, nhúng mô-men bù $T_{ff}$ trực tiếp vào 29-bit CAN ID.
    • Ước lượng trạng thái 2 tầng & Chống trượt bánh: Kết hợp AHRS Mahony 1 kHz định hướng 3D từ cảm biến Bosch BMI088 (SPI 10 MHz) với bộ lọc Kalman 2 trạng thái thích nghi. Khi phát hiện trượt bánh từ hai phần dư độc lập (Yaw & Linear), hiệp phương sai $R_v(s)$ tự động tăng tối đa $\approx 351\times$ để cách ly encoder bánh xe và tin cậy vào IMU.
    • Hệ thống chẩn đoán an toàn đa tầng: Topic /motor_status bitmask 6-bit giúp phân biệt “bánh xe dừng bình thường” với “mất nguồn / đứt cáp CAN”, tích hợp cơ chế tự phục hồi Bus-Off của Bosch M_CAN IP và màn hình LCD ST7789 hiển thị telemetry thời gian thực.

    Kiến trúc phần mềm

    Goal

    Design, build and tune an industrial-grade embedded robot controller that makes the microcontroller a first-class ROS 2 node — low latency, hard real-time behaviour, hardware safety through layered diagnostics, and strict memory-resource management.

    Key engineering features

    • Native ROS 2 node (micro-ROS over USB CDC): talks straight to the ROS 2 computation graph through the Micro-XRCE-DDS client at 12 Mbit/s, with full static type contracts (sensor_msgs/JointState, geometry_msgs/Twist) and per-topic QoS (Reliable for commands, Best Effort for telemetry).
    • Self-healing DDS session (4-phase state machine with ping hysteresis): a four-phase state machine drives the node lifecycle; ping hysteresis (3 s interval / 150 ms timeout / 3 misses) removes the topic flickering that USB bus jitter used to cause.
    • Fully static message assembly (zero dynamic allocation): every string array and vector in JointState is bound to static memory, so heap fragmentation cannot occur inside the real-time control loop.
    • Dual-FDCAN architecture for RobStride motors: two motors run independently on FDCAN1 and FDCAN3 at 1 Mbit/s, both keeping their factory Node ID 1 — a motor can be swapped without reflashing an ID — with the feedforward torque $T_{ff}$ packed directly into the 29-bit CAN ID.
    • Two-stage state estimation with slip rejection: a 1 kHz Mahony AHRS derives 3D orientation from a Bosch BMI088 (SPI at 10 MHz) and feeds a two-state adaptive Kalman filter. When two independent residuals (yaw and linear) agree that a wheel is slipping, the covariance $R_v(s)$ grows by up to $\approx 351\times$, isolating the wheel encoders and trusting the IMU instead.
    • Layered safety diagnostics: a 6-bit bitmask on /motor_status distinguishes “wheel stopped normally” from “power lost / CAN cable broken”, alongside the Bosch M_CAN Bus-Off auto-recovery and an ST7789 LCD showing live telemetry.

    Công nghệ sử dụng

    • Hệ thống nhúng (Embedded): C/C++, ARM Cortex-M7 (STM32H723), FreeRTOS, STM32CubeMX, GNU Arm Toolchain, Makefile, Linker Script Memory Mapping.
    • Hệ sinh thái Robot: ROS 2 Jazzy, micro-ROS Client (rcl, rmw_microxrcedds, rosidl), eProsima Micro-XRCE-DDS.
    • Giao tiếp công nghiệp: USB CDC ACM, FDCAN (Bosch M_CAN IP, 29-bit CAN ID, MIT mode), SPI Master DMA, UART DMA Ring Buffer.
    • Xử lý tín hiệu & Điều khiển: AHRS Mahony 1 kHz (DCM/Quaternion), Bộ lọc Kalman thích nghi (Adaptive Slip-Aware EKF), Differential Drive Odometry.
    • Công cụ kiểm thử & Gỡ lỗi: Logic Analyzer (FDCAN/SPI), PlotJuggler, RViz2, ST-Link V3, SEGGER SystemView.

    Quá trình thực hiện

    1. Phân tích Kiến trúc & Tối ưu Bộ nhớ: Phân tách bản đồ bộ nhớ STM32H7 (DTCM cho .data tốc độ cao, AXI-SRAM cho .bss, DMA buffer và 2 khối Heap 96 KB riêng biệt). Cấu hình colcon.meta tối giản hóa thư viện libmicroros.a.
    2. Hiện thực Tầng Giao vận USB & Máy trạng thái DDS: Vá bảng hàm vtable USBD_Interface_fops_HS lúc chạy, xây dựng vòng đệm RX 2048 B và thiết kế máy trạng thái 4 pha với cơ chế trễ ping chống mất kết nối giả.
    3. Hiện thực Driver Dual-FDCAN & Giao thức RobStride: Xây dựng driver FDCAN phi chặn cho hai bus độc lập, xử lý lượng tử hóa 16-bit MIT control, unwrap góc quay đa vòng và cơ chế tự giải cứu Bus-Off.
    4. Tích hợp IMU Mahony 1 kHz & Bộ lọc Kalman Chống Trượt: Đọc cảm biến BMI088 qua SPI, chạy thuật toán Mahony bù trọng lực, xây dựng bộ quan sát Kalman 2 trạng thái với hàm phóng đại phương sai $R_v(s) = R_0(1 + 350s^2)$.
    5. Tích hợp Hệ thống & Đóng gói Phân tầng: Phối hợp 5 task FreeRTOS bằng osDelayUntil + re-anchor, xây dựng UART DMA logging không chặn deadline, hoàn thiện GUI chẩn đoán LCD ST7789 và kiểm thử tích hợp toàn diện với ROS 2 Jazzy.

    Kết quả & hướng phát triển

    Hệ thống hoạt động ổn định liên tục với tần số giao tiếp micro-ROS 50 Hz, nhận lệnh và phản hồi telemetry mượt mà, ước lượng vận tốc chính xác ngay cả khi robot bị nhấc bổng hoặc trượt bánh trên bề mặt ma sát thấp.

    Hướng phát triển tiếp theo:

    • Nâng cấp driver SPI2 đọc BMI088 sang chế độ DMA để tối ưu hóa thời gian CPU của task 1 kHz.
    • Cấu hình MPU cho vùng nhớ DMA để bật D-Cache cho toàn bộ hệ thống.
    • Nhúng thư viện tf2_msgs để publish trực tiếp biến đổi tọa độ odom -> base_link từ vi điều khiển.

    Hình ảnh

    Technology used

    • Embedded: C/C++, ARM Cortex-M7 (STM32H723), FreeRTOS, STM32CubeMX, GNU Arm toolchain, Makefile, linker-script memory mapping.
    • Robotics ecosystem: ROS 2 Jazzy, micro-ROS client (rcl, rmw_microxrcedds, rosidl), eProsima Micro-XRCE-DDS.
    • Industrial communication: USB CDC ACM, FDCAN (Bosch M_CAN IP, 29-bit CAN ID, MIT mode), SPI master DMA, UART DMA ring buffer.
    • Signal processing and control: 1 kHz Mahony AHRS (DCM/quaternion), adaptive slip-aware Kalman filter, differential-drive odometry.
    • Test and debug tools: logic analyser (FDCAN/SPI), PlotJuggler, RViz2, ST-Link V3, SEGGER SystemView.

    How it was built

    1. Architecture analysis and memory tuning: splitting the STM32H7 memory map (DTCM for hot .data, AXI-SRAM for .bss and the DMA buffers, two separate 96 KB heaps), and a colcon.meta that trims libmicroros.a to the minimum.
    2. USB transport layer and DDS state machine: patching the USBD_Interface_fops_HS vtable at run time, building the 2048 B RX ring buffer, and designing the four-phase state machine whose ping hysteresis rejects false disconnects.
    3. Dual-FDCAN driver and RobStride protocol: a non-blocking FDCAN driver for two independent buses, 16-bit MIT-control quantisation, multi-turn angle unwrapping, and Bus-Off self-recovery.
    4. 1 kHz Mahony IMU and slip-aware Kalman filter: reading the BMI088 over SPI, running gravity-compensated Mahony, and building the two-state Kalman observer with the variance-inflation law $R_v(s) = R_0(1 + 350s^2)$.
    5. System integration and layered packaging: coordinating the five FreeRTOS tasks with osDelayUntil plus re-anchoring, adding UART DMA logging that never misses a deadline, finishing the ST7789 diagnostic GUI, and running full integration tests against ROS 2 Jazzy.

    Results and next steps

    The controller runs continuously and stably at a 50 Hz micro-ROS rate, accepting commands and returning telemetry smoothly, and its velocity estimate stays accurate even when the robot is lifted off the ground or its wheels slip on a low-friction surface.

    Next steps:

    • Move the BMI088 SPI2 driver to DMA to free CPU time in the 1 kHz task.
    • Configure the MPU for the DMA regions so the D-cache can be enabled system-wide.
    • Embed tf2_msgs so the microcontroller can publish the odom -> base_link transform directly.
