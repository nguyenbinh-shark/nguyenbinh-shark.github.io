    Simscape Multibody Robotics · Bài Viết Phụ — Hướng Dẫn Cài Đặt Plugin Simscape Multibody Link Cho SolidWorks Bằng Lệnh smlink_linksw Simscape Multibody Robotics, Appendix - Installing the Simscape Multibody Link Plugin for SolidWorks with smlink_linksw

    6 phút đọcminute read

    Ngày đăng:Published: August 19, 2026

    Khi làm chủ mô phỏng động lực học robot trong MATLAB/Simscape Multibody, công việc tốn nhiều công sức nhất không phải là viết thuật toán điều khiển mà là dựng lại toàn bộ kết cấu cơ khí 3D: xác định gốc tọa độ, tính khối lượng từng link, đo trọng tâm (CoG), lập ma trận quán tính ($I_{xx}, I_{yy}, I_{zz}\dots$) và gắn từng khớp nối (Joint).

    Thay vì phải nhập thủ công từng con số dễ sai sót, MathWorks cung cấp plugin chính thức mang tên Simscape Multibody Link. Công cụ này cho phép bạn xuất trực tiếp toàn bộ bản lắp ráp (Assembly) từ SolidWorks sang Simscape chỉ với một cú click chuột.

    Bài viết này sẽ hướng dẫn bạn quy trình cài đặt, đăng ký liên kết bằng lệnh smlink_linksw và bật Add-In trong SolidWorks một cách chuẩn xác, tránh triệt để các lỗi phân quyền thường gặp.

    1. Yêu Cầu Chuẩn Bị Trước Khi Cài

    Trước khi thực hiện, hãy đảm bảo hệ thống của bạn đã có:

    1. SolidWorks (đã cài đặt và hoạt động bình thường).
    2. MATLAB & Simulink đã cài sẵn 2 toolbox: Simscape và Simscape Multibody.
    3. Bộ cài đặt plugin Simscape Multibody Link (.zip):
      • Truy cập trang tải chính thức: MathWorks Simscape Multibody Link Downloads
      • Chọn đúng phiên bản MATLAB bạn đang dùng (Ví dụ: R2023b, R2024a…).
      • Tải file nén dạng .zip cho Windows 64-bit (ví dụ: smlink.r2024a.win64.zip).

    2. Quy Trình Cài Đặt 4 Bước Chi Tiết

    flowchart TD
    A["Bước 1: Tắt SolidWorks & Mở MATLAB với quyền Run as administrator"] --> B["Bước 2: Chạy lệnh cài đặt install_addon(...)"]
    B --> C["Bước 3: Đăng ký liên kết với SolidWorks bằng smlink_linksw"]
    C --> D["Bước 4: Mở SolidWorks và kích hoạt Add-In"]

    Bước 1: Mở MATLAB với quyền Administrator

    [!IMPORTANT] Đây là bước then chốt nhất. Cả quá trình giải nén add-on và đăng ký file DLL vào hệ thống Windows (COM/Registry) đều yêu cầu quyền Quản trị viên cao nhất.

    1. Tắt hoàn toàn SolidWorks và MATLAB đang mở trên máy.

    2. Tìm icon MATLAB trên màn hình Desktop hoặc menu Start.

    3. Click chuột phải $\rightarrow$ Chọn Run as administrator.

    Bước 2: Cài đặt Add-on từ file .zip vừa tải

    1. Trong giao diện MATLAB, tại khung Current Folder, điều hướng đến thư mục chứa file .zip bạn vừa tải về ở phần chuẩn bị.
    2. Tại cửa sổ Command Window, gõ lệnh sau và nhấn Enter:
    install_addon('smlink.r2024a.win64.zip')

    (Lưu ý: Thay đổi tên file smlink.r2024a.win64.zip cho đúng với tên file thực tế bạn đã tải).

    Bước 3: Đăng ký liên kết với SolidWorks bằng smlink_linksw

    Sau khi addon được cài đặt xong, tiếp tục gõ lệnh sau vào Command Window của MATLAB:

    smlink_linksw

    • Kết quả hiển thị: MATLAB sẽ tự động dò tìm bản cài SolidWorks trên máy và đăng ký thư viện DLL. Nếu thành công, màn hình sẽ hiển thị thông báo:
      Simscape Multibody Link was successfully connected to SolidWorks.

    [!TIP] Nếu sau này bạn cần nâng cấp phiên bản MATLAB hoặc muốn gỡ bỏ plugin khỏi SolidWorks, bạn chỉ cần mở MATLAB (Admin) và chạy lệnh hủy liên kết:

    smlink_linksw -u

    Bước 4: Kích hoạt Add-In trong SolidWorks

    1. Khởi động phần mềm SolidWorks.
    2. Trên thanh menu trên cùng, vào mục Tools $\rightarrow$ Chọn Add-Ins… (hoặc click vào icon bánh răng Options $\rightarrow$ Add-Ins…).
    3. Cuộn danh sách xuống mục Other Add-Ins, bạn sẽ thấy dòng Simscape Multibody Link.
    4. Tích chọn vào cả 2 ô kiểm:
      • Active Add-ins: Bật plugin ngay trong phiên làm việc hiện tại.
      • Start Up: Tự động kích hoạt plugin mỗi lần SolidWorks khởi động.
    5. Nhấn OK để lưu lại.

    3. Kiểm Tra Xuất Thử File CAD Sang Simscape

    [!TIP] Tải mô hình mẫu thực hành: Nếu chưa có sẵn file lắp ráp robot, bạn có thể tải trọn bộ mô hình 3D CAD cánh tay robot Universal Robot UR3 (đầy đủ chi tiết và bản lắp ráp .SLDASM) tại đây để thực hành ngay: 👉 Tải Trọn Bộ 3D CAD Robot UR3 (Google Drive)

    Để kiểm tra xem plugin đã hoạt động chuẩn xác hay chưa:

    1. Mở bản lắp ráp robot (.SLDASM ví dụ bản lắp ráp UR3 vừa tải về) trong SolidWorks.
    2. Vào menu Tools $\rightarrow$ Simscape Multibody Link $\rightarrow$ Export $\rightarrow$ Simscape Multibody…

    1. Đặt tên và lưu file với định dạng .xml. SolidWorks sẽ tự động xuất ra:
      • File cấu trúc .xml.
      • Một thư mục chứa toàn bộ file hình học 3D (.STEP hoặc .STL).

    1. Mở MATLAB, gõ lệnh sau để mở mô hình trong Simulink:
    smimport('Ten_Robot.xml')

    MATLAB sẽ tự động vẽ toàn bộ sơ đồ khối gồm các khối Solid, Rigid Transform, Revolute Joint… và mở cửa sổ Mechanics Explorer 3D để bạn quan sát mô hình chuyển động thực tế.

    4. Xử Lý Các Lỗi Thường Gặp (Troubleshooting)

    ❌ Lỗi 1: Error: Access is denied hoặc không tìm thấy đường dẫn SolidWorks

    • Nguyên nhân: MATLAB không được cấp quyền Administrator khi thực thi lệnh đăng ký DLL.
    • Cách khắc phục: Đóng MATLAB hoàn toàn, chuột phải vào icon MATLAB và chọn Run as administrator, sau đó chạy lại smlink_linksw.

    ❌ Lỗi 2: Không xuất hiện mục “Simscape Multibody Link” trong Add-Ins SolidWorks

    • Nguyên nhân: Lệch phiên bản giữa MATLAB và SolidWorks (ví dụ MATLAB quá cũ so với bản SolidWorks).
    • Cách khắc phục: Thông thường bản MATLAB cùng năm hoặc mới hơn sẽ hỗ trợ tốt cho SolidWorks các bản trước đó 1–2 năm. Hãy kiểm tra Bảng tương thích MathWorks CAD Support.
