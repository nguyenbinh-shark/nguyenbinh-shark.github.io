    Mô phỏng MATLAB — Động học & không gian làm việc robot 5 khâu

    Bài viết chi tiết về mảng mô phỏng / động học của dự án robot 5 khâu. Đọc bài tổng hợp tại Robot Song Song 5 Khâu — Pick & Place. Toàn bộ hằng số cơ cấu (L0 = 55, L1 = L4 = 70, L2 = L3 = 130 mm) lấy từ thông số cơ khí.

    Mục tiêu phần mô phỏng: kiểm chứng thuật toán động học trước khi chạy cơ khí thật. MATLAB đóng vai trò nguồn sự thật (ground truth): giải động học ngược (IK) dạng đóng, vẽ không gian làm việc, rồi so khớp kết quả với firmware C và mô phỏng JavaScript trên HMI.

    1. Mô hình cơ cấu & hệ trục

    Cơ cấu five-bar phẳng: hai động cơ cố định tại hai chân đế A = (0, 0) và C = (L0, 0). Mỗi nhánh là một chuỗi 2 khâu:

       A ──L1──> khuỷu 1 ──L2──>  P (đầu công tác)
   C ──L4──> khuỷu 2 ──L3──>  P

    Hai nhánh hội tụ tại cùng một điểm P = (x, y) — đây chính là ràng buộc đóng tạo nên đặc tính song song.

    2. Động học ngược (IK) dạng đóng

    Bài toán: cho P = (x, y), tìm hai góc động cơ θ₁ (tại A) và θ₂ (tại C). Xét nhánh trái: khuỷu E₁ nằm trên đường tròn bán kính L1 quanh A, đồng thời cách P đúng L2:

    \[|E_1 - P| = L_2 \;\Rightarrow\; (L_1\cos\theta - x)^2 + (L_1\sin\theta - y)^2 = L_2^2\]

    Triển khai:

    \[L_1^2 + x^2 + y^2 - 2L_1(x\cos\theta + y\sin\theta) = L_2^2\]

    Đưa về dạng tuyến tính theo cosθ, sinθ:

    \[\underbrace{2L_1 x}_{A}\cos\theta + \underbrace{2L_1 y}_{B}\sin\theta = \underbrace{x^2 + y^2 + L_1^2 - L_2^2}_{C}\]

    Giải bằng thay thế tang nửa góc t = tan(θ/2) (cosθ = (1−t²)/(1+t²), sinθ = 2t/(1+t²)), phương trình trở thành bậc hai theo t:

    \[\theta = 2\arctan\!\frac{B \pm \sqrt{A^2 + B^2 - C^2}}{A + C}\]

    Điều kiện khả thi: căn dưới dấu sqrt không âm — disc = A² + B² − C² ≥ 0. Hình học, điều này tương đương P nằm trong vành khuyên quanh A: |L2 − L1| ≤ |AP| ≤ L1 + L2, tức bán kính 60–200 mm — khớp đúng thông số trong portfolio.

    Nhánh phải tính tương tự, chỉ cần tịnh tiến x → x − L0 và dùng L4, L3. Dấu ± chọn theo dấu của y để cố định một chế độ lắp (khuỷu hướng ra ngoài), tránh nhảy nghiệm giữa hai nhánh.

    3. Không gian làm việc

    Không gian làm việc WS là giao ba điều kiện hình học:

    1. P thuộc vành khuyên nhánh trái (quanh A, bán kính |L2−L1|..L1+L2),
    2. P thuộc vành khuyên nhánh phải (quanh C, bán kính |L3−L4|..L4+L3),
    3. sau khi giải IK và chuẩn hóa wrap360(θ), cả hai góc nằm trong tầm servo [0°, 180°].

    Điều kiện (3) rất dễ bị bỏ sót: atan2 có thể trả góc lệch ±360°, nếu so trực tiếp với [0,180] sẽ từ chối nhầm những điểm hợp lệ → phải wrap360() trước khi kiểm.

    4. Mã MATLAB (chạy được)

    %% five-bar linkage: IK dạng đóng + không gian làm việc
%  Trần Nguyên Bình — Robotics & Mechatronics
clear; clc;

L0 = 55;  L1 = 70;  L2 = 130;  L3 = 130;  L4 = 70;   % mm (theo cơ cấu thực)

%% ---- 1) Không gian làm việc: giao hai vành khuyên ----
[X, Y] = meshgrid(-220:2:220, -220:2:220);
dA = hypot(X, Y);                          % khoảng cách tới A
dC = hypot(X - L0, Y);                     % khoảng cách tới C
ann1 = (abs(L1-L2) <= dA) & (dA <= L1+L2); % vành khuyên trái
ann2 = (abs(L3-L4) <= dC) & (dC <= L4+L3); % vành khuyên phải
WS   = ann1 & ann2;

figure; hold on; axis equal; grid on;
contourf(X, Y, double(WS), 1, 'LineStyle','none');
colormap([1 1 1; 0.2 0.6 0.9]);
plot(0, 0, 'ks', 'MarkerFaceColor','k'); plot(L0, 0, 'ks', 'MarkerFaceColor','k');
viscircles([0 0], L1+L2, 'Color',[.6 .6 .6]);        % giới hạn ngoài nhánh trái
viscircles([L0 0], L4+L3, 'Color',[.6 .6 .6]);
title('Không gian làm việc — giao hai vành khuyên'); xlabel('x (mm)'); ylabel('y (mm)');

%% ---- 2) IK: (x,y) -> theta1, theta2 (độ) ----
[th1, th2, ok] = ik5(60, 120, L0, L1, L2, L3, L4);   % điểm thử
fprintf('IK tại (60,120): θ1=%.2f°  θ2=%.2f°  khả thi=%d\n', th1, th2, ok);

%% ---- 3) Kiểm chứng FK: (θ1,θ2) -> (x,y) phải khớp đầu vào ----
[xr, yr] = fk5(th1, th2, L0, L1, L2, L3, L4);
fprintf('FK kiểm chứng: (%.2f, %.2f) — sai số %.3f mm\n', xr, yr, hypot(xr-60, yr-120));

% ---------- hàm ----------
function [th, ok] = solveBranch(x, y, La, Lb)
    A = 2*La*x;  B = 2*La*y;  C = x^2 + y^2 + La^2 - Lb^2;
    disc = A^2 + B^2 - C^2;
    ok = disc >= 0;
    th  = 2*atand( (B - sqrt(max(disc,0))) / (A + C) );   % dấu '-' = một chế độ lắp
    th  = wrap360(th);
end

function [th1, th2, ok] = ik5(x, y, L0,L1,L2,L3,L4)
    [th1, ok1] = solveBranch(x,    y, L1, L2);            % nhánh trái tại A
    [th2, ok2] = solveBranch(x-L0, y, L4, L3);            % nhánh phải tại C
    ok = ok1 && ok2;
    % ràng buộc tầm servo (theo cơ cấu thực):
    inServo = (th1 >= 0 && th1 <= 180) && (th2 >= 0 && th2 <= 180);
    ok = ok && inServo;
end

function [x, y] = fk5(th1, th2, L0,L1,L2,L3,L4)
    % vị trí khuỷu
    E1 = [L1*cosd(th1), L1*sind(th1)];
    E2 = [L0 + L4*cosd(th2), L4*sind(th2)];
    % P = giao hai đường tròn (E1,R=L2) và (E2,R=L3) — chọn nghiệm nhất quán
    d = norm(E2 - E1);
    a = (L2^2 - L3^2 + d^2) / (2*d);
    h = sqrt(max(L2^2 - a^2, 0));
    Pm = E1 + a*(E2 - E1)/d;
    P  = Pm + h*[- (E2(2)-E1(2)), (E2(1)-E1(1))] / d;     % chọn bên (theo dấu y đầu vào)
    x = P(1);  y = P(2);
end

function a = wrap360(a), a = mod(a, 360); end

    5. Kiểm chứng chéo ba nền tảng

    Sự tin cậy đến từ việc ba triển khai độc lập cho cùng kết quả:

    Nền tảngVai tròĐầu ra
    MATLABSự thật tham chiếu (analytic)θ₁, θ₂ cho mỗi (x, y)
    Firmware C (ESP32-S3)Thực thi real-time trên vi điều khiểncùng θ₁, θ₂
    JavaScript (HMI)Động học thuận từ góc servo thậtvẽ lại cơ cấu khớp vị trí thật

    Quy trình kiểm chứng: sinh ngẫu nhiên nhiều điểm trong WS → giải bằng cả ba → so sai số. Nếu ba đường ra khớp nhau (sai số < dung sai servo) thì thuật toán đúng trước khi chạy cơ khí — tiết kiệm rủi ro hỏng hóc phần cứng.

    6. Giới hạn & hướng phát triển

    • IK hiện nội suy trong không gian góc → đầu cuối đi đường cong. Hướng nâng cấp: nội suy đường thẳng Descartes (chạy IK cho từng điểm trung gian dọc tuyến đường).
    • Mở rộng MATLAB sang mô phỏng động lực học (mô hình khâu-lực, nội lực chuỗi kín) để định cỡ động cơ.
    • Thêm tránh kỳ dị ở biên WS.
